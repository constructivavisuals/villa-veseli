IMPLEMENTACE:
=============

1. Komponenta InteractiveMap:
   - useState pro: hoveredZone (string|null), selectedZone (string|null)
   - Wrapper div s position: relative
   - <img src="/images/aerial-golden.jpg"> jako základ
   - <svg> overlay s viewBox odpovídajícím rozměrům obrázku (zjisti skutečné px rozměry aerial-golden.jpg)
   - Pro každou zónu: <polygon points="..." /> s:
     - fill: transparent (default) → rgba barva (hover/selected)
     - stroke: none (default) → 2px white (hover/selected)
     - cursor: pointer
     - transition: all 0.3s ease
     - onMouseEnter, onMouseLeave, onClick handlery

2. Tooltip:
   - Při hoveru zobrazit label zóny jako malý tooltip u kurzoru
   - Bílý text na poloprůhledném tmavém pozadí

3. Detail panel:
   - Slide-in zprava (width: 440px, na mobilu 100%)
   - Background: rgba(17,17,17,0.97), backdrop-filter blur
   - Zavírací křížek
   - Nadpis zóny
   - Popis textem
   - Fotky (kliknutí = lightbox zvětšení)
   - Tlačítko "Domluvit prohlídku" → scroll na kontakt

4. Efekt ztlumení:
   - Když je nějaká zóna v hoveru, obrázek pod ním se mírně ztmaví (filter: brightness(0.65))
   - A hovered polygon bude mít jasnější výplň — opticky "vynikne"

5. Instrukce pod obrázkem:
   - Text: "Kliknutím na část areálu zobrazíte podrobnosti" (malé, šedé)

6. Navigace:
   - Do Nav přidej: { id: "explore", label: "Areál" } mezi Galerie a Parametry

7. Responsivita:
   - Pod 768px: detail panel = fullscreen overlay
   - SVG se škáluje s obrázkem (preserveAspectRatio)
